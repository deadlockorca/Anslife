## 5. Màu sắc và kiểu chữ hiện tại (để sếp duyệt)
### 5.1 Bảng màu chính đang áp dụng
- Nền chính: `#f3eee7`
- Nền panel/card: `#ffffff`
- Màu chữ chính: `#1f2733`
- Màu chữ phụ: `#607086`
- Màu viền: `#d8e0ea`
- Màu thương hiệu primary: `#446084`
- Màu primary đậm: `#334862`
- Màu nhấn accent: `#d26e4b`
- Màu trạng thái danger: `#b20000`
- Màu trạng thái success: `#7a9c59`

### 5.2 Kiểu chữ đang áp dụng
- Font nội dung/body: `Whitney SSm` (fallback: `Source Sans 3`, `Segoe UI`, `Arial`, `sans-serif`)
- Font heading: `Lyon Display Web` / `Lyon Text Web` (fallback: `Spectral`, `Times New Roman`, `serif`)
- Font cho input/button/ui control: theo `font-ui` = `Whitney SSm` (fallback cùng body)
